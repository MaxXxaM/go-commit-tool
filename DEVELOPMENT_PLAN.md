# План разработки: Go Multi-Module Development Utility

## Вопросы для уточнения

Перед началом реализации, пожалуйста уточните:

1. **Название утилиты**: Какое название предпочитаете?
   - Варианты: `gomodutil`, `go-workspace`, `gomm` (go module manager), `godev`, `goutil`

2. **Минимальная версия Go**: Go 1.21+ подходит?

3. **Стиль именования команд**:
   - Вариант 1: `gomodutil switch local`
   - Вариант 2: `gomodutil local`
   - Какой стиль предпочтительнее?

4. **Shared директория по умолчанию**: Где должна быть shared директория?
   - `../shared` относительно текущего проекта?
   - Глобальная `~/go-modules-shared`?
   - Определяется пользователем в конфиге?

5. **Анализ breaking changes**:
   - Достаточно ли базового анализа (удаление/изменение публичных функций)?
   - Или нужен более глубокий семантический анализ?

6. **Тестирование перед релизом**:
   - Какие команды запускать для тестов? `go test ./...`?
   - Нужна ли поддержка кастомных тестовых команд?

После ответов на эти вопросы начнём с Итерации 1!
